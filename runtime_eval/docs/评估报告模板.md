### 2.2 综合质量分（@«score_k»，难度加权）

> 公式：`S_q = 0.40·Recall + 0.25·(0.5·MRR + 0.5·NDCG) + 0.35·(0.40·Precision + 0.60·ContextRecall)`
> KB 总分 = Σ(难度权重 × S_q) / Σ权重（难度权重 easy 1.0 / normal·medium 1.5 / hard 2.0），仅在含黄金的用例上计算。

> PASS 判定：`Recall ≥ 0.5` 且 `首个相关命中排名 ≤ 3` 且 `ContextRecall ≥ 0.8` 三者同时满足。
