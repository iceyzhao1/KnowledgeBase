# 实体图谱页（功能①）设计稿

> 状态：已与用户确认（2026-06-15）。下一步可据此写实现计划（writing-plans）。
> 范围：仅功能① —— 实体图谱页的实体 **合并 / 删除 / 改本体节点**，及随之的边重算。
> 不含：功能③（本体图谱页，单独设计稿）。

## 1. 目标与背景

跑完挖掘后，给人一个**图谱视角**收拾实体：
- **合并**：把指向同一真实事物的多个实体并成一个；
- **删除**：去掉垃圾/错误实体；
- **改本体节点（改类型）**：给 `__untyped__`（暂无类型）实体挂上正确的本体节点类型，或纠正错挂的类型。

改完后**边自动重算**，所见即所得。

### 关键事实（决定了整个方案）

- **边是算出来的，不是人画的。** `ontology_entity_relations` 由 `reaggregate_edges` + `persist_edges`
  从**提及表**（每个实体在哪段话出现过：resolved_entity_id + 当前 node_type/canonical_name + quote）
  重跑关系抽取 + NPMI 得到。系统本就是按"人在关之间合并/改名/改类型 → 边整体重算"设计的。
- **合并会改变共现计数**（p_h / p_t / p_ht），NPMI 基于共现概率，因此合并后的边权重**不能简单"接线"**
  （把被删实体的边头接到主实体），必须把涉及实体重新统计。删除、改类型同理。
- **实体唯一约束**：`(domain_id, node_type, canonical_name)`。改类型/改名撞上已有 (类型,名字) → 即变成合并。

## 2. 边重算策略（已与用户拍定）

- **时机：每次确认后立即重算**（所见即所得）。顶部短暂显示"重算中"→"已同步"。
  - 放弃方案：攒一批改动手动点重算（页面会与边不同步，易忘）。
- **范围：scoped —— 只重算 `{被改实体} ∪ {其直接邻居}` 之间的边。**
  - **这是精确的，不是近似**：NPMI 分母是段落总数（不随合并/删除/改类型变化），
    所以未触及的实体对，其 p_h/p_t/p_ht 全不变、边权重数学上不变，重算它们纯属浪费。
  - 实现上：取受影响实体所在**段落**的全部提及（邻居即由此自然带出），在该子集上
    重跑关系抽取 + NPMI；掉到阈值（confidence < 0.3）以下的边消失；范围外的边不动。

## 3. 交互设计

### 3.1 选择
- 单击 = 选中一个实体（右侧出详情）。
- 按住 Ctrl/⌘ 单击 = 多选（≥2 个）→ 用于合并。
- 空白处单击 = 清空选择。

### 3.2 单个实体面板
- 展示：canonical_name、当前类型徽标、出现篇数 / 提及次数、entity_id。
- **改类型**：下拉框列出 active 本体节点类型 + "暂无类型(`__untyped__`)"；选新类型 → 应用。
- **删除实体**：危险按钮。

### 3.3 多选面板（合并）
- 列出所选实体卡片。
- **合并后主名**：下拉选哪个实体当主（其 name/type 存活，其余被并入）。
- **合并为一个实体**按钮。

### 3.4 确认步（删除/合并/改类型共用的安全阀）
- 点动作后**不立即提交**，先弹内联提示，并**在图上把受影响的边高亮成橙色虚线**。
- 提示文案说明：将改写哪些提及、涉及几个邻居、会重跑 NPMI、可能撞名变合并 / 边会消失。
- 「确认并重算」才真正提交；「取消」回退高亮。
- v1 **不做真·撤销**，由确认步兜底；撤销列为后续增强。

### 3.5 重算反馈
- 提交后顶部 pill：「● 有未重算的改动」（橙）→ 后台重算完 →「✓ 已与边同步」（绿）。
- 图实时刷新（节点消失/合并、边权重变化/消失）。底部 toast 提示动作结果。

## 4. 后端落点

复用已有积木，最大化减少新代码：

| 动作 | 复用 | 新增 |
|------|------|------|
| 合并 | 提及改指主实体（resolve_mention 同型逻辑）| scoped 重算调用 |
| 改类型 | `rebind_untyped_entities` 的 UPDATE 模式（推广到任意类型；撞名→并入）| scoped 重算调用 |
| 删除 | 删实体 + 其提及 | scoped 重算调用（只动邻居边）|

**真正要新写的：**
1. **scoped 重算函数**：给定受影响 entity_id 集合，查这些实体所在段落的全部提及，
   在该子集上跑 `reaggregate_edges` / `persist_edges`，只覆盖该子集内的边。
2. **三个 API 端点**：合并 / 改类型 / 删除（各自调用对应 mutation + scoped 重算，返回新图局部）。
3. **Vue 实体图谱页**：SVG/canvas 图、选择、右侧动作面板、确认高亮、重算状态 pill。

## 5. 边界与非目标
- 不做本体图谱（功能③，独立稿）。
- 不做真·撤销（后续）。
- 不改两道关（entity_review / ontology_review）的既有流程；本页是关后/独立的整理视角。
- 删除为硬删（删实体+提及），由确认步防误删。

## 6. 验收要点
- 合并后：被并实体消失、提及全归主实体、相关边权重按新共现重算、范围外边不变。
- 改类型撞名：自动并入同名实体，等价合并结果。
- 删除：实体+提及+相连边清除，邻居间不凭空生边。
- 全程"所见即所得"：每次确认后图与边一致。
